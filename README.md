# Financial Project

## Описание  
Этот проект реализует функции для работы с финансовыми операциями, включая:  
- Фильтрацию операций по их статусу  
- Сортировку операций по дате  
- Маскирование номеров карт и счетов  
- Загрузку данных  

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/RiSofi/Home_work_project
```
2. Установите зависимости:
```
poetry install
```
