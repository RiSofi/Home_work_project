# Financial Project

## Описание  
Этот проект реализует функции для работы с финансовыми операциями, включая:  
- Фильтрацию операций по их статусу  
- Сортировку операций по дате  
- Маскирование номеров карт и счетов  
- Загрузку данных
- Фильтрация операций по валюте
- Извлечение описаний транзакций
- Генерацию номеров карт
- Логирование вызовов функций с помощью декоратора

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/RiSofi/Home_work_project
```
2. Установите зависимости:
```
poetry install
```
## Декоратор логирования (log)

Проект включает декоратор log, который логирует вызовы функций, записывая информацию о входных аргументах, результате выполнения и возможных ошибках.

### Использование
```
from src.decorators import log

@log(filename="mylog.txt")
def add(a, b):
    return a + b
    
@log()
def divide(a, b):
    return a / b
```
- Если передать filename, логи сохраняться в указанный файл.
- Если не указывать filename, логи выводятся в консоль.

## Тестирование
Проект использует 'pytest' для автоматического тестирования функций.

### Запуск тестов
Для запуска тестов выполните команду:
```
pytest
```
или для более подробного вывода
```
pytest -v
```
### Покрытие тестами
Тесты проверяют следующие функции:

- filter_by_state(data, state) – фильтрация списка транзакций по статусу.

- sort_by_date(data, descending=True) – сортировка списка транзакций по дате.

- get_mask_card_number(card_number) – маскирование номера карты.

- get_mask_account(account_number) – маскирование номера счета.

- mask_account_card(input_data) – определение типа входных данных (номер карты или счета) и их маскирование.

- filter_by_currency(transactions, currency_code) - генератор, который возвращает транзакции с заданной валютой. Если таких транзакций нет, возвращает пустой итератор.

- card_number_generator(start, end) – генератор номеров банковских карт в формате XXXX XXXX XXXX XXXX.

- transaction_descriptions(transactions) – генератор, возвращающий описание каждой транзакции.
- Тесты декоратора log, которые проверяют:
   + Логирование вызова функции.
   + Запись логов в файл tests/test_melog.txt
   + Корректность обработки исключений (ZeroDivideError).

### Требования
Перед запуском тестов убедитесь, что установленны необходимые зависимости для poetry:
```
poetry add --group dev pytest
```
В pytest для анализа покрытия кода надо поставить библиотеку pytest-cov:
```
poetry add --group dev pytest-cov
```
